# Architectural Decisions

Index of all Architecture Decision Records (ADRs). Full records live in
`docs/architecture/decisions/`, written from `templates/adr.md`.

## Rules

- Any change to architecture, tech stack, data model, or external contracts
  requires an ADR **before** implementation.
- ADRs are immutable once accepted. To reverse one, write a new ADR that
  supersedes it.
- Number sequentially: `ADR-0001`, `ADR-0002`, …
