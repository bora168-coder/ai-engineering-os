# Diagrams

All project diagrams: system topology, data flow, ER diagrams, sequence diagrams.

Rules:

- Prefer text-based sources (Mermaid, PlantUML, D2) so diagrams diff and
  review like code. Keep the source next to any exported image.
- Every diagram states what it shows and its last-verified date.
- A wrong diagram is worse than none — update or delete when the system changes.
