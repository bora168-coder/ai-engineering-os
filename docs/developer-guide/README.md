# Developer Guide

Everything a new developer needs to contribute:

1. **Setup** — prerequisites, install, run locally, run tests. Must work by
   copy-paste; test it on a clean machine when it changes.
2. **Project layout** — where things live and why.
3. **Conventions** — links to `.ai/STYLE_GUIDE.md`, `.ai/WORKFLOW.md`,
   `.ai/RULES.md` rather than duplicating them.
4. **Common tasks** — add an endpoint, add a migration, add a page, …
