# Examples

Reference projects built with VOID AI OS, showing what a filled-in `.ai/`
directory looks like on a real project.

Planned (tracked in `.ai/ROADMAP.md` of this template repo):

- `employee-management/` — CRUD web app: filled PROJECT/ARCHITECTURE/TECH_STACK,
  real ADRs, a completed sprint history.
- `ai-chat/` — LLM-powered app: shows research → ADR → implementation flow for
  model/provider choices.
- `banking-system/` — domain-heavy example: rich `memory/business.md` and
  security-first workflow.

Each example is a snapshot, not a maintained product — its value is the `.ai/`
directory, not the code.
